# SIA Template Documentation Pack

Dokumen:
1. `.docs/PRD.md` — spesifikasi produk utama.
2. `.docs/TEMPLATE-GUIDE.md` — panduan mengenal dan menjalankan template.
3. `.docs/CUSTOMIZATION-GUIDE.md` — panduan mengubah dan mengembangkan template.
4. `.docs/PROJECT-ASSIGNMENT.md` — panduan tugas project kelompok.
5. `.docs/ACCOUNTING-MODULE-GUIDE.md` — panduan konsep modul akuntansi contoh.

Baca PRD terlebih dahulu untuk memahami cakupan sistem. Panduan teknis harus diperiksa kembali terhadap source code aktual sebelum dibagikan kepada mahasiswa.
